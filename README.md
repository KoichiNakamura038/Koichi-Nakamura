# Takahiro Sato — Portfolio

A Three.js-powered portfolio showcasing Takahiro Sato's decade of fullstack engineering experience across Japanese and global markets.

## Features

- Immersive WebGL background with sakura particles and geometric accents
- Japanese-inspired aesthetic with bilingual content (EN / JA)
- Scroll-driven animations via GSAP
- Responsive layout with accessibility considerations
- Featured global project: [Datylon](https://www.datylon.com/)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- Vite
- Three.js
- GSAP (ScrollTrigger)
